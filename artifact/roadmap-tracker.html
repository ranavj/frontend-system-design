How to run each build

The shipping loop

01 / SPIKE

Read just enough

Sirf itna padho ki build shuru ho jaaye. Deep dive baad mein — pehle haath gande karo.

02 / BUILD

Implement it small

Scope chhota rakho — ek concept, ek working demo. Library use karne se pehle khud likhne ki koshish karo.

03 / SHIP & EXPLAIN

Commit + articulate

Repo mein push karo, README mein "kyun A over B" likho, checkbox tick. Yahi interview answer ban jaayega.

Build-first roadmap · resources external references hain, current content verify kar lena. Har checkbox ek shippable project · progress locally browser mein save hota hai.
